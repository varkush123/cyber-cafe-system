Cyber Cafe Management System

Description:
A web-based Cyber Cafe Management System built using Django and MySQL.

Features:
- Login system
- Customer management
- Computer management
- Billing system

Requirements:
Django== 6.0.6
mysql-connector-python== 9.7.0
MySQL = 8.0

Setup Instructions:
1. Create database using MySQL.sql file
2. Update MySQL username and password in project
3. Install dependencies using requirements.txt
4. Run server: python manage.py runserver
